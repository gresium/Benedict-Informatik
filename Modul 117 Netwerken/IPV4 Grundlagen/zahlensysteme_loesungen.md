## Binär → Dezimal

Jede Stelle hat den Wert einer Zweierpotenz (…, 128, 64, 32, 16, 8, 4, 2, 1). Die Werte der Stellen mit einer 1 werden addiert.

**a) 1101**  
8 + 4 + 1 = **13**

**b) 101110**  
32 + 8 + 4 + 2 = **46**

**c) 11001000**  
128 + 64 + 8 = **200**

**d) 01011101**  
64 + 16 + 8 + 4 + 1 = **93**

**e) 1011101101**  
512 + 128 + 64 + 32 + 8 + 4 + 1 = **749**

## Dezimal → Binär

Von der Zahl wird immer die grösste passende Zweierpotenz abgezogen. Die Stellen mit abgezogenem Wert bekommen eine 1, alle anderen eine 0.

**a) 37**  
37 − 32 = 5  
5 − 4 = 1  
1 − 1 = 0  
→ **100101**

**b) 82**  
82 − 64 = 18  
18 − 16 = 2  
2 − 2 = 0  
→ **1010010**

**c) 149**  
149 − 128 = 21  
21 − 16 = 5  
5 − 4 = 1  
1 − 1 = 0  
→ **10010101**

**d) 246**  
246 − 128 = 118  
118 − 64 = 54  
54 − 32 = 22  
22 − 16 = 6  
6 − 4 = 2  
2 − 2 = 0  
→ **11110110**

**e) 811**  
811 − 512 = 299  
299 − 256 = 43  
43 − 32 = 11  
11 − 8 = 3  
3 − 2 = 1  
1 − 1 = 0  
→ **1100101011**
